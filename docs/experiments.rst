Experiment Records
==================

One page per published run: summary, figures, histories, model hashes and provenance.
Generated by :repo:`scripts/publish/export_run.py` and annotated with the endpoints of
:doc:`results`. Downloads are path-free copies from
``published/experiments/<slug>/public/``; epochs in model file names are checkpoint
epochs (training epoch + 17).
Values for all runs, including those without a page, are in
:repo:`published/results/validation_endpoints.csv`.
