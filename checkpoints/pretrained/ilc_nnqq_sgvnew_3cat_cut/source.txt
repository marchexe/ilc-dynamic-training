Canonical pretrained checkpoint bundle

This directory is self-contained for the pretrained model artifacts used by guarded PBT fine-tuning.
The small checkpoint/config files are stored as real files, not symlinks, so configs do not depend on `/data/suehara/part/suehara/...`.

Files:
  base_config.yaml
  data_config.auto.yaml
  net_best_epoch_state.pt
  net_epoch-17_state.pt
  net_epoch-17_optimizer.pt
  metadata.json

Original source paths and SHA256 values are recorded in metadata.json.
Datasets are not committed; see datasets/manifests/20250218_ilc_nnqq_sgvnew_parquet.json.
